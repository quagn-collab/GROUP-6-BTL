📖 Chú Thích Biểu Đồ

🏗️ Inheritance (Kế Thừa) ✓ Entity → User → Admin, Seller, Bidder ✓ Item → Art, Electronics, Vehicle ✓ ItemFactory → BaseItemFactory → Concrete Factories
🔌 Interface Implementation ✓ Auction implements Subject (Observer Pattern) ✓ Bidder implements Observer ✓ Factories implement ItemFactory
🔗 Composition & Association ✓ Auction chứa BidTransaction (1:*) ✓ Auction liên kết với Seller, Item, Bidder ✓ Seller sở hữu Item
🎨 Design Patterns ✓ Observer: Thông báo thay đổi phiên đấu giá ✓ Factory Method: Tạo các loại Item khác nhau ✓ Template Method: BaseItemFactory cung cấp nền tảng
📝 Thông Tin Kiến Trúc Chi Tiết:
  • Entity: Lớp trừu tượng cơ sở cho mọi thực thể, có id và createdAt.
  • User & Hierarchy: Gồm Admin (quản trị viên), Seller (người bán), Bidder (người tham gia đấu giá).
  • Auction: Quản lý phiên đấu giá, triển khai Subject pattern để thông báo cho Observers.
  • Factory & Observer Pattern: Đảm bảo tính mở rộng (Open/Closed Principle) và cập nhật thời gian thực.
